## Кто что пишет — в одной строке

| | Пишет код, который… | Папки | На входе | На выходе |
|---|---|---|---|---|
| 🧭 1 | показывает всё пользователю и поднимается одной командой | `backend/` `frontend/` `deploy/` | `run_agent_stream()`, функции аналитики | API, интерфейс, docker-compose |
| 📄 2 | превращает PDF/DOCX в пункты с метаданными, версиями и правами и кладёт их в индекс | `ingest/` + `retrieval/index.py`, `embedder.py`, `bm25_index.py` | файлы из `data/raw/` | заполненный Qdrant + BM25, `documents.jsonl` |
| 🔎 3 | по вопросу находит нужные пункты и измеряет качество всей системы | `retrieval/` (поиск) `eval/` `analytics/` | индекс от 📄 | `search()`, метрики, отчёты, функции аналитики |
| 🤖 4 | рассуждает в несколько шагов и отвечает с цитатами или отказывает | `agent/` | `search()` от 🔎 | `run_agent_stream()` |

```
 data/raw ──📄──▶ индекс ──🔎 search()──▶ 🤖 агент ──▶ 🧭 backend ──▶ 🧭 frontend
                                │                         │
                                └──🔎 eval (метрики) ◀────┘ логи ──🔎 analytics──▶ 🧭 дашборд
```

## Правило против блокировок

Никто не ждёт соседа. Пока модуля нет — работаешь на заглушке по контракту из [../02-contracts.md](../02-contracts.md):
- 🧭 — `AGENT_MODE=mock` (фейковый ответ агента)
- 🤖 — `retrieval/mock.py` (поиск по списку в памяти) — 🔎 отдаёт его в первый час
- 🔎 — до индекса от 📄 берёт `chunks.jsonl` с синтетики и индексирует сам в песочнице
- 🔎 для аналитики — `fake_logs.py`, пока нет живых логов

Закончил раньше — бери задачу из бэклога соседа по цепочке (📄 ↔ 🔎 ↔ 🤖 ↔ 🧭) и скажи об этом на синке.
