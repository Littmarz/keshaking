## 7. Ключевые решения (продумать до ТЗ)

### Чанк = пункт

```
chunk_id:     reg-0042::3.2.1
section:      3.2.1
heading_path: ["Регламент согласования договоров", "3. Подписание", "3.2 Агентские договоры"]
text:         "3.2.1. Агентский договор на сумму свыше 1 000 000 руб. подписывает генеральный директор…"

Что эмбеддим: "Регламент согласования договоров > 3. Подписание > 3.2 Агентские договоры\n3.2.1. Агентский договор…"
```
Заголовки в начале текста для эмбеддинга сильно помогают поиску, а `text` для цитаты храним чистым.

### Логика актуальности (👥 П1, черновик)

1. Явная пометка «утратил силу» / «отменён приказом…» → `cancelled`
2. Документ упомянут как заменённый другим действующим → `superseded`
3. Несколько редакций одного документа (один номер / название) → действует последняя с `effective_from ≤ сегодня`
4. Дат нет вообще → `unknown`, по нему ищем, но агент предупреждает
5. Старые редакции **не удаляем** из индекса, только помечаем → агент может сказать «раньше было X, сейчас Y»

### Что сохраняем в payload Qdrant

`chunk_id, doc_id, doc_title, section, section_title, heading_path, text, page, status, effective_from, access_level` + payload-индексы на `status`, `access_level`, `doc_id` для быстрых фильтров.
