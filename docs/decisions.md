### D-001. Только локальная LLM, OpenAI-совместимый API
- Дата / кто: 21.11 / команда
- Контекст: условия запрещают внешние LLM API в работе решения
- Решение: Ollama или vLLM (один рантайм на весь спринт, выбор — D-004), клиент через OpenAI-совместимый интерфейс → модель меняется одной строкой в `.env`
- Почему: переносимость, бенчмарк разных моделей без переписывания кода

### D-002. Чанкинг по структуре документа (пункт/подпункт)
- Дата / кто: 21.11 / команда
- Решение: один чанк = один пункт (с заголовками-родителями в `heading_path`), а не N символов
- Почему: требование ссылаться на конкретный пункт; точные цитаты

### D-003. Логика действующей редакции — черновик (👥 П1: 📄 + 🤖 доработают до 26.11)
- Правила по приоритету:
  1. Явная пометка «утратил силу» / «отменён» → `cancelled`
  2. Документ указан в `supersedes` у другого действующего → `superseded`
  3. Несколько редакций одного документа → действует последняя с `effective_from ≤ REFERENCE_DATE` (дата из конфига, по умолчанию сегодня — чтобы eval не зависел от дня запуска)
  4. Конфликт разных документов: более поздний (lex posterior) > более специальный (lex specialis) > вышестоящий по иерархии (lex superior). Не можем решить → статус `conflict`, показываем оба источника
- Почему: стандартные принципы юридической коллизии, легко объяснить жюри
