# Условия хакатона (из Q&A организаторов)

> Источник: Google-док с ответами организаторов. После ТЗ 26.11 — обновить этот файл (Claude по просьбе капитана).

## Задача партнёра

Сотрудники тратят 30 мин – 2 ч на поиск информации о внутренних процессах (кто подписывает агентский договор, какой регламент действует, кто ответственный за этап). Информация разбросана по регламентам, приказам, базам знаний. 100–300 таких запросов в месяц = 50–300 человеко-часов. До 40% запросов остаются без ответа или получают устаревшую информацию → ошибки в документах, задержки согласований, повторная работа.

Наша мотивация (из заявки): сократить время поиска, снизить ошибки из-за устаревших правил, ИИ-агент во внутреннем контуре, ответы со ссылками на конкретные пункты, измеримое качество, готовность к пилоту.

## Данные

| Вопрос | Ответ |
|---|---|
| Как дадут данные | Файлами. API нет. Объём небольшой |
| Что внутри | База корпоративных регламентов, описание продуктов с правилами лицензирования, примеры вопросов пользователей, тестовый набор вопрос-ответ |
| Чаты / почта | **Не будет** |
| Форматы, даты, версии | В детальном ТЗ **26 ноября** |
| Иерархия документов | Не задана — **логику действующей редакции придумываем и обосновываем сами** |
| Документы обезличены | Да, можно хранить на своём сервере |

## Логика и функциональность

- Отвечать в том числе на вопросы, затрагивающие **несколько регламентов**.
- При противоречиях логику выбирает команда. **Обоснованный отказ** с источниками и причиной неопределённости допустим.
- Права доступа сотрудников — не обязательно, но **плюс** на демо.
- Интеграция с корп. системой допустима, идентификацию пользователя можно **имитировать**.
- Действия по итогам ответа (создать заявку и т.п.) — не требуются.

## Модели и инфраструктура

- Серверов не дают. Ограничений по GPU/VRAM/RAM нет.
- Решение работает с **локальной моделью** во внутреннем контуре, без внешних LLM API. **Название модели — в описании продукта.**
- Любая локальная модель. Но решение **не должно быть дорогим в эксплуатации**.
- Для разработки можно любые инструменты и внешние API (например, сгенерировать синтетику через ChatGPT/Claude). Работа решения и демо жюри — в **изолированном контуре**.

## Сдача

- **Видео-демо + описание продукта** → отбор финалистов.
- Финалистам — **ссылка на открытый репозиторий**.
- Может быть запрошено **живое демо** до определения победителей.
- В видео можно показывать названия документов, фрагменты и цитаты из материалов хакатона.

## Оценка — 6 равновесных критериев (Приложение 1)

Известны:
1. **Соответствие задаче партнёра** — релевантность + аналитика: разбор неудачных поисков, что ищут пользователи, чего нет в базе, логирование действий, аналитика по поиску.
2. **Агентность** — от 0 (один запрос к модели) до **3 (автономный многошаговый агент)**. Целимся в 3.

- Скорость отдельно не оценивается, но входит в корректность реализации.
- Методика сравнения ответов с эталоном не задана.

Остальные 4 критерия неизвестны → см. [05-questions-to-organizers.md](05-questions-to-organizers.md).
