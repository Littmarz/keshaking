# sandbox/ — песочница до ТЗ

Каждый экспериментирует в своей папке: `sandbox/captain/`, `sandbox/data/`, `sandbox/agent/`, `sandbox/eval/`.
Общие синтетические документы (готовит Claude) — в `sandbox/synthetic/`.

Код отсюда **не идёт в продакшен как есть** — после ТЗ переносим удачное в нужный модуль.
Тренировочные документы не коммитим (они в `.gitignore`).
