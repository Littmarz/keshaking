# sandbox/ — только учёба, никакого кода решения

⛔ По правилам хакатона до **10:00 МСК 26.11** писать код нельзя, а конкурсной разработкой считается только код, созданный в ходе спринта (см. [../docs/00-conditions.md](../docs/00-conditions.md)).

Поэтому:
- Туториалы (FastAPI, LangGraph, Qdrant…) проходим **вне этого репозитория** и ничего из них не сохраняем и не переносим в решение.
- В git отсюда ничего не коммитим, кроме этого README.
- Можно хранить заметки и проектные решения **текстом**: `sandbox/<имя>/NOTES.md` (что узнал, какие проблемы нашёл, какие решения предлагаю).
- Синтетические документы и тестовые вопросы (данные, не код) — в `sandbox/synthetic/`. Сами файлы документов в git не кладём (`.gitignore`).

После 26.11 код пишем с нуля в модулях (`ingest/`, `retrieval/`, `agent/`, …), опираясь на заметки и [../docs/02-contracts.md](../docs/02-contracts.md).

Папки: `sandbox/captain/`, `sandbox/docs/`, `sandbox/search/`, `sandbox/agent/`, `sandbox/synthetic/`.
