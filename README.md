# KESHAKING — ИИ-агент поиска ответов по корпоративным документам

> Хакатон «ИИКузница» · трек «Аналитик данных» · задача «ИИ Агент поиска ответов на вопросы по корп. документам» · заказчик — служба качества Софтлайн
> **Спринт идёт: 26.11 10:00 → 28.11 12:00 МСК** (срок из личного кабинета, с продлением). Стенд держим до **03.12 23:59 МСК**.
> Что именно требуется — **[docs/00-conditions.md](docs/00-conditions.md)** (срез по карточке и брифу от 26.11).

## 🎯 Три обязательных сценария (на одном прототипе)

1. **Ответ по регламенту** — с названием документа и номером пункта, с условиями и исключениями; нужны несколько регламентов — собрать из них.
2. **Уточнение при неоднозначности** — один конкретный вопрос сотруднику (дирекция? этап?), следующий ход учитывает и вопрос, и ответ.
3. **Пополнение базы через службу качества** — нет ответа → обращение в локальную очередь → сотрудник качества отвечает и подтверждает → агент использует подтверждённое знание на похожих вопросах.

Корпус — 4 DOCX (проектная и пресейловая деятельность дирекций ИБ, ДБРЦТ, Техдирекции). Модель — `qwen3:8b` в Ollama на Mac, без внешних LLM API. Контрольные прогоны — [eval/datasets/control.jsonl](eval/datasets/control.jsonl) (16 сценариев).

## 🗂 Структура монорепо

```
keshaking/
├── README.md                 ← ты здесь
├── docs/                     📝 общие доки + team/ (личные планы)
├── core/                     👥 общие схемы (контракты) — меняем только по согласованию команды
├── ingest/                   📄 парсинг, пункты, метаданные, версии, доступы
├── retrieval/                📄 построение индекса · 🔎 гибридный поиск, реранкер, фильтры
├── agent/                    🤖 LLM-клиент, граф LangGraph, промпты, инструменты
├── backend/                  🧭 FastAPI: API, БД, логи, обращения в службу качества
├── frontend/                 🧭 React: чат, уточнения, источники, форма службы качества
├── eval/                     🔎 контрольные прогоны (datasets/control.jsonl), метрики, отчёты
├── analytics/                🔎 расчёты по логам (после обязательных сценариев)
├── deploy/                   🧭 docker-compose, стенд по URL, Ollama на хосте
├── data/                     raw/ (4 DOCX заказчика) processed/ — не в git
├── models/                   веса моделей (не в git)
└── sandbox/                  личные заметки (sandbox/<имя>/NOTES.md)
```

В каждой папке лежит свой `README.md`: кто владелец, какие файлы там будут и за что они отвечают.

## 🎯 Что делаем (в одну фразу)

Локальный многошаговый ИИ-агент (без внешних LLM API) отвечает сотрудникам Софтлайн по внутренним регламентам со ссылкой на конкретный пункт, сохраняя условия и исключения; при неоднозначности задаёт уточняющий вопрос, а если ответа в регламентах нет — передаёт вопрос в службу качества и после подтверждения использует её ответ как новое знание.
