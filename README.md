## 🗂 Структура монорепо

```
keshaking/
├── README.md                 ← ты здесь
├── docs/                     📝 общие доки + team/ (личные планы)
├── core/                     👥 общие схемы (контракты) — меняем только через PR с ревью всех
├── ingest/                   📄 парсинг, пункты, метаданные, версии, доступы
├── retrieval/                📄 построение индекса · 🔎 гибридный поиск, реранкер, фильтры
├── agent/                    🤖 LLM-клиент, граф LangGraph, промпты, инструменты
├── backend/                  🧭 FastAPI: API, БД, логи, доступы
├── frontend/                 🧭 React: чат, источники, аналитика, документы
├── eval/                     🔎 прогон, метрики, отчёты (+🤖 LLM-судья)
├── analytics/                🔎 расчёты по логам: неудачные поиски, темы, пробелы
├── deploy/                   🧭 docker-compose, офлайн-сборка
├── data/                     raw/ processed/ (не в git)
├── models/                   веса моделей (не в git)
└── sandbox/                  личные эксперименты до ТЗ (sandbox/<имя>/), в main не тянем
```

В каждой папке лежит свой `README.md`: кто владелец, какие файлы там будут и за что они отвечают.

## 🎯 Что делаем (в одну фразу)

Локальный многошаговый ИИ-агент (без внешних LLM API) отвечает на вопросы сотрудников по регламентам и правилам лицензирования. Каждый ответ подтверждается **ссылкой на конкретный пункт документа**. Агент сам выбирает **действующую редакцию**, а если ответа нет или документы противоречат друг другу, **обоснованно отказывает** и показывает источники. Каждый запрос логируется, дашборд показывает неудачные поиски и пробелы в базе.
