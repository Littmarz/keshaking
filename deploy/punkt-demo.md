# Запуск демо «Пункт» через Docker Compose

Нужны Node.js с npm и Docker Compose. В корне репозитория выполните:

```bash
npm --prefix frontend run build:docker
```

Откройте `http://127.0.0.1:8080`. Интерфейс и API работают на одном порту. Сборка подтягивает образы и зависимости. После запуска Docker держит контейнер в фоне. Если порт занят, задайте другой через `PUNKT_PORT`.

Чтобы использовать локальную Qwen, запустите Ollama на Mac с моделью
`qwen3:8b` и включите режим модели при запуске контейнера:

```bash
AGENT_MODE=real npm --prefix frontend run build:docker
curl -fsS http://127.0.0.1:8080/api/health
```

Поле `llm` должно быть `ok`. По умолчанию контейнер обращается к Ollama
через `http://host.docker.internal:11434`. Адрес и модель можно задать
через `LLM_BASE_URL` и `LLM_MODEL`. Эта команда использует учебные источники.

Для поиска по регламентам положите файлы `ib-project.docx`,
`ib-presale.docx`, `dbrct-project.docx` и `tech-project.docx` в `data/raw/`.
Если есть готовый `data/processed/chunks.jsonl`, поиск использует его.
Папка данных подключается только для чтения. При замене файлов перезапустите
контейнер, чтобы перечитать индекс.

```bash
AGENT_MODE=real AGENT_SOURCES=documents npm --prefix frontend run build:docker
```

### Служба качества с тестовым почтовым ящиком

```bash
AGENT_MODE=real AGENT_SOURCES=documents PUNKT_TEST_MAIL=1 COMPOSE_PROFILES=quality-mail npm --prefix frontend run build:docker
```

Откройте Mailpit на `http://127.0.0.1:8025`. При создании обращения агент
ставит письмо в очередь, и оно приходит в локальный тестовый ящик
`quality@demo.invalid`. Порт ящика можно изменить через `PUNKT_MAIL_PORT`.
Ответ и его подтверждение выполняются в разделе «Служба качества» в «Пункте».
После подтверждения задайте вопрос другими словами в новом чате.

Почта включается только для этого профиля запуска. При временной недоступности
Mailpit очередь сохраняется в SQLite и отправка повторяется. Сам ящик хранится
в отдельном томе `punkt-mail`.

Номер виден внизу интерфейса. `build:docker` и `npm run build` из
`frontend/` используют общий локальный счётчик `.punkt-build-number`.
Первый запуск резервирует `0.0.1`, следующие увеличивают последний компонент.
У каждой рабочей копии свой счётчик. Перезапуск готового контейнера сохраняет
номер. При прямом вызове Docker Compose можно передать готовый номер через
`PUNKT_BUILD_VERSION`.

Три учебных сценария запускаются кнопками в интерфейсе. Для третьего сценария подтвердите разъяснение в «Службе качества», откройте новый чат и задайте «За сколько дней юристы согласуют ТКП?».

```bash
docker compose -f deploy/docker-compose.yml logs -f
docker compose -f deploy/docker-compose.yml down
```

История чата и обращения сохраняются в томе `punkt-data`. Это отдельная база демо. Для переноса на другую машину код берут из репозитория и там запускают ту же команду. Текущий профиль использует учебную базу и демонстрационные роли.

Контейнеры при сборке используют официальные образы Node.js 24 и Python 3.12, а также `uv` 0.13.10. Node.js лицензирован по MIT, Python по PSF, uv по MIT или Apache 2.0. Образы также включают компоненты Debian со своими лицензиями.
